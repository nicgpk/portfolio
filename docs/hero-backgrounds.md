# Quieter hero background exploration

The existing cloud remains the default. Three reversible query options are available on the same homepage: `?background=horizon`, `?background=dune` and `?background=orbit`. The allowlist ignores unknown values. The comparison page is `review/hero-backgrounds/index.html`.

- Horizon: a low, broad waveform with open space above. Recommended for the clearest introduction.
- Dune: two large soft forms at the sides, retaining a quiet center.
- Orbit: one broad elliptical arc, with less ink below it.

These are original mathematical forms sampled by the existing halftone renderer. They replace photographic detail only in the opt-in options. The dots, monochrome paper/ink, orange typography, unchanged hero copy and links, bounded cursor brush, 24fps ceiling, pause control and offscreen suspension remain. No image model, external artwork or runtime dependency is required. Options skip the cloud texture fetch in the animated renderer. Matching 800/1600px indexed PNG posters are generated by `scripts/build-hero-backgrounds.mjs` using the existing palette encoding approach. Desktop alternatives are 43,933 / 45,110 / 57,186 bytes; mobile alternatives are 33,321 / 36,333 / 44,146 bytes.

`scripts/review-hero-backgrounds.mjs` checks four backgrounds at 320/390/768/1440px, loaded matching reduced-motion posters, no document overflow and automated WCAG contrast/accessibility. All three live options verify real mouse brush uploads, unchanged heading geometry, fading trails, fixed-phase visible ink changes, pause/resume and context-loss fallback. Unknown options preserve the default. `scripts/review-clouds.mjs` checks the original default renderer, preferences and offscreen behavior.

The screenshot comparison uses fixed static posters so ambient time does not distort the choice. Live cursor captures are labeled separately. Query selection uses JavaScript; without it, the original static hero remains, while all comparison screenshots are directly readable. The original poster can also load briefly before the query-selected poster. A final chosen default would be authored into the page to remove that extra initial request. Actual devices, Safari/Firefox, screen readers, GPU cost and production performance remain unverified. This is a branch/draft-PR exploration, not a production change or a final background selection.
